# 历史业务配方（参考）
本目录保留早期工作报告、请示、预算、跟踪表及演示稿配方，均为原创 DEMO 数据。它们不作为本轮插件生成与字体验收的交付物。
当前默认只提供三个元素范本：Word 一个文件、Excel 一个文件（基础样式与数据图表两个工作表）、PowerPoint 一个文件。请使用[当前图库](../style-gallery.md)或[范本技能](../../skills/office-document-styles/SKILL.md)中的入口，另存工作副本后替换数据。
本轮内容修改通过实际插件 Office.js 动作完成；字体与结构从原生导出读取，预览来自 Microsoft Office 原生页面或工作表。详细结果以各范本的真实核验记录为准，不将历史外部脚本文件作为插件验收。
插件现已支持原生 Word 全局样式、TOC/PAGE 字段、页面参数，以及 Excel 打印布局等动作。使用前查询当前运行时能力；安装目录的版本元数据与热更新代码版本须分别报告。
