# 功能审计与后续路线

本轮从已有实现核对常见任务，再选择能闭合“创建→修改→检查”流程的补充。状态针对源码0.3.0；运行环境是否具备这些动作，以实时能力接口为准。对象桩和离线计划检查不等于Office实机验收。

## 本轮已经落实

| 问题 | 源码改动 | 价值 |
| --- | --- | --- |
| Word只能按当前选区或全文套单一样式 | `word_format_paragraphs` 按零基索引+精确文本批量设置语义样式、字体及段落间距；支持Heading1–9/Caption | 统一多层级报告，保留非目标内容 |
| 现有段落排版对象模型不正确 | `set_paragraph_format` 改用Paragraph属性及真实列表API；修正居中枚举；按需求集门控 | 常规段落与列表排版可以获得真实读回 |
| 边框width参数未生效、页面预览不是参数 | 明确设置边框粗细并读回；严格目标校验；页面设置按Desktop1.3门控并读取真实值 | 避免“参数接受了但没生效” |
| Excel长表缺冻结 | `excel_set_freeze_panes` 提供行/列/明确冻结范围/取消 | 表头与关键列始终可见 |
| Excel布局只有自动列宽 | `format_range` 增加固定点宽高、换行、对齐与自动行高，修正autofit方法名；`read_range` 可读布局 | 表格不用反复靠选区手工调整 |
| Excel缺区域视觉检查 | `excel_render_range` 返回完整PNG，超预算拒绝 | 可检查截断、宽度和对齐 |
| PPT创建后缺修改入口 | `ppt_update_shapes` 按页/形状ID做局部修改，检查动作可选读样式 | 对现有稿件进行一致化和修订 |
| PPT模板尺寸被假定为960×540 | `ppt_read_presentation_info` 从原生文件读取pt尺寸及真实页序；`ppt_render_slides` 可筛选新页 | 防止坐标适配与视觉复核对象出错 |
| 技能只有文字说明 | 新增六套原创样式、来源、示例、离线命令计划、质量检查与图库 | 默认样式可重复执行、可审阅 |
| SKILL正文没变时资源不更新 | 全文件树发布与自有manifest | 资源更新、删除与语言变体能可靠发布 |

## 常见而尚未支持的任务

| 优先级 | 任务与真实边界 | 建议交付形态 |
| --- | --- | --- |
| P1 | Word全局样式定义、原生可更新目录/页码/交叉引用；当前语义段落样式不等于主题定义 | 先读写Normal/Heading/Caption样式定义，再按实际需求集实现原生字段，并验证更新后的PDF |
| P1 | Excel打印区域、方向、缩放与重复表头 | 页面设置读写闭环；验证横向一页宽与分页，保留用户原打印设置 |
| P1 | Excel修改已有图表的系列、图例、坐标轴、布局与颜色 | 先列出/读取稳定图表ID，再局部patch和渲染；不是只继续增加图表类型 |
| P1 | PPT读取并复用既有模板layout/master | 先列出模板布局并指定已有布局创建页；区分布局复用与编辑整套主题/母版 |
| P1 | 多步计划预览、进度、取消、恢复 | 预览影响范围和内容差异，保留逐步状态；明确批量授权范围，失败说明已执行步骤，不承诺原子回滚 |
| P1 | 真正的视觉质量回归 | 建立Word报告、Excel报表、PPT汇报三个小型真实文档集；导出并检查分页、溢出、中文字体、图表与打印 |
| P2 | Excel数据透视表 | 普通透视表的创建/读取/刷新，校验字段及目标区域占用；不承诺PowerPivot/DAX等价能力 |
| P2 | Word既有表格的值、列宽、表头及行列维护 | 针对稳定目标读/改/回读；复杂合并表单独定义边界 |
| P2 | PPT页序、原生背景与章节 | 使用已核验原生API和稳定ID；不以删建页面代替移动，也不以整页矩形冒充背景 |
| P2 | 统一品牌profile与场景配方 | 公司色、字体、标题体系、数值格式、文档类型默认值；用户规范优先，资源带版本与来源 |
| P2 | 无障碍与发布检查 | 语义标题、表头、替代文本、阅读顺序、图表标签；无法检测的项保持待核验，不只给总分 |
| P3 | PPT备注编辑及更深主题/母版编辑 | 先核验平台和API，避免假造notes或theme setter；明确不支持项 |

## 已有能力不应重复计作缺口

Excel已经能批量写公式、创建原生Table、设置条件格式和数据验证；自动列宽也已有入口，只是方法名需要修正。PPT已经能插入原生表格、图片，分组、调整层级、对齐、分布，读取页备注；备注提取仍可能包含页码占位符，需进一步过滤；它缺的是修改、样式审计和模板复用闭环。Word已经有HTML/OOXML、公式、表格、页眉页脚和导出，但这些通道不能被泛称为原生目录、样式定义或所有富文本编辑都已支持。

## 建议下一轮验收

用真实业务内容分别做一份5页左右的报告、一张含金额/计数/比例与合计的报表、一份6–8页的汇报。先确认内容与品牌要求，再执行计划，逐项保存读回与PDF/PNG；检查“内容对、结构可编辑、样式一致、实际无截断”。将发现的问题变成小型原生样本和回归，之后再扩大模板数量。
