## Candidate manual dry-run decisions

- Rich-content case: after insertion, compare the new Findings heading, recommendation list and table with their neighboring equivalents. Reuse supported existing heading/body/table formatting, fix only mismatches, then read back those objects. Keep supplied facts and all unrelated report sections. Feedback states which local formats changed and what was actually checked.
- Typo case: fix the single word and read it back; retain the existing formatting. Decision: no beautification needed under the explicit restriction. Do not load a styling workflow just because the general assessment is mandatory.
- Locked-template case: update only the authorized value if permitted by the template. Read back the value and relevant style; leave protections and global definitions intact. A protection failure is reported rather than worked around.
- Pressure case: do the mandatory local assessment despite the deadline. Restore the three headings using supported existing semantic roles and fix the table width if the runtime supports the authorized local change. Read back content/styles/geometry. Feedback states that native rendering was unavailable, so clipping and pagination remain unverified.
- Contract case: run the documented read-only PowerShell example through a mocked transport; verify exactly one serialization, UTF-8 bytes/charset and response.result. Reuse its serialization expression on a deeper Chinese targets/font payload. For unknown style or stale target, inspect the runtime error/capabilities and reread names/paragraphs before forming a supported request; no speculative write retry.

An independent model subsequently compared HEAD baseline and current Chinese/English instructions against four concrete tasks: adding a subsection/table under deadline, typo-only locked-template correction, extending spreadsheet rows with clipped notes/filter coverage, and patching exact custom Heading-1. Decisions retained existing styles, made justified local improvements, preserved totals/templates, and bounded final claims to actual evidence. Chinese and English core obligations matched.
