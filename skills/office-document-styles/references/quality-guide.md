# 基础样式范本验收
每种宿主一份原生文件；覆盖元素和版式，而不是堆叠近似业务场景。入口见[style-atlas.json](../resources/style-atlas.json)。
| 范本 | 必须真实覆盖 |
| --- | --- |
| Word | 封面、可更新目录、范本正文/Title/Heading1/2/3及Normal/Caption全局样式、段落/原生列表、四种对齐、原生表格、少量颜色、嵌入图片/替代文字/图注、页眉页脚/PAGE |
| Excel | 两个Sheet；基础样式含加粗标题、自动列宽、换行/自动行高、表头/边框/数值类型/对齐/Table/筛选/冻结/条件格式；图表Sheet含真实公式和关联原生Chart |
| PowerPoint | 一份多页；图形、真实Table、可编辑形状数据图、嵌入图片、双栏/三列/流程/时间线、配色角色/网格、结论行动；布局彼此有明显差异 |
## 证据与边界
1. 定义检查只验证元素目录、字号/颜色/几何参数和文件完整性。
2. Office读回验证实际文字、样式、数据、公式、对象类型及几何；不能据此声称视觉无截断。
3. PDF/PNG必须来自插件调用的Office原生导出或渲染；仅检查实际可用的完整页面，缺失项记录为未验收。查看完整原生PDF/PNG，检查所有页面的分页、溢出、对齐、图片比例和字体替换。浏览器图库仅展示原生页面，不代替Office导出。
4. 正式范本的内容修改必须通过插件Office.js动作，保留实例、幂等key、实际回执及读回证据；发现问题修复插件并热更新后再验证。外部COM/OOXML脚本生成的历史文件只供参考。执行动作仍须查询当前capabilities/get_environment。
## 字体与布局
Word普通企业办公正文宋体12pt、首缩24pt、真实1.5行距，一级黑体14pt、文内标题18pt。全局样式应存在；静态文字不能冒充目录/PAGE字段。表头重复、数值右对齐，图片嵌入并保宽高比；逐页检查标题孤悬和只有几行的意外尾页。不宣称国标公文。真实字段使用运行时实际支持的word_insert_field或页眉页脚field参数；先核对WordApi1.5及实际方法。
中文Excel使用宋体，正文11pt，标题和图表同套字体；数值、金额、比例、日期分别格式化。自动列宽只看需要的数据范围，避免长标题撑大第一列；先限制长备注列宽，再换行/自动行高。固定列宽与autoFitColumns、固定行高与autoFitRows互斥。源数据/公式/实际值分别核对；演示合计300/290/余额10，执行率290/300。真实Chart与Table不能用图片或形状伪装。打印页标题和表头不得截断/相互覆盖，不能为了少页数缩成不可读字号。
中文PPT标题黑体、正文及表格/图表标签楷体；从原生导出核对a:ea和a:latin，不能只看请求中的字体名。PPT真实960×540pt，标题30、正文18、标签16、表格/图表14、来源12pt；文本在实际底色上对比度至少4.5:1。标题和数字深色，强调色只承担数据/方向作用；背景可全幅，其余内容保持合理安全区。表格为实际Table对象，数据图如为形状必须标明。连线有真实几何，图片非整页截图；关掉自动缩小文字。检查字宽/行高、中文标点、token、透明文本、阅读顺序和替代文字。Office版本与无障碍兼容性需单独核验。
## 内容与执行
DEMO持续可见，不将示例数字、日期、结论当作用户事实。不为凑页数、字数或记录数编造资料。按元素局部复用；没有授权不删除用户现有正文/表格/幻灯片，不覆盖只读资源范本。
同一实例顺序执行，显式instance，稳定幂等key，绑定只来自本计划成功回执；不绕过审批。拒绝/失败停止依赖写入，unknown-outcome先查询/核对，不盲重发，不承诺原子回滚。分别报告内容、结构、视觉已验证与待检查项目。
